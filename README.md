# RadarX AI

A Python Streamlit hackathon project for competitive intelligence radar tracking.

## Directory Structure

```
radarx-ai/
  app.py
  requirements.txt
  .env
  .gitignore
  README.md
  data/
    market_events.csv
```

## Setup & Installation

1. Activate your virtual environment:
   ```bash
   .venv\Scripts\activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run application:
   ```bash
   streamlit run app.py
   ```
